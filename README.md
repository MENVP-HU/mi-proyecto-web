# Mi Proyecto Web

## Descripción

Este proyecto consiste en la creación de un sitio web básico utilizando HTML, con el objetivo de aprender a trabajar con Git y GitHub, gestionar ramas y documentar los cambios realizados.

## Instalación

1. Clonar el repositorio desde GitHub.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo `index.html` en un navegador web.

## Estructura del proyecto

- `index.html`: página principal del sitio web.
- `.gitignore`: archivo que indica qué archivos y carpetas debe ignorar Git.
- `README.md`: documentación del proyecto.

## Mejoras implementadas

- Menú de navegación con enlaces internos.
- Formulario de contacto creado con HTML.

## Tecnologías utilizadas

- HTML5
- Git
- GitHub
